Everything you need for privacy

Fine-grained controls so you decide exactly what stays hidden.

💬

Blur messages

All messages in the open chat stay blurred until you hover over them.

📋

Preview blur

Last-message previews in the left sidebar are hidden from prying eyes.

🖼️

Media protection

Images, videos, stickers and other media are blurred separately from text.

👤

Profile pictures

Avatars across the interface stay blurred for extra discretion.

⏱️

Timed Auto-Blur

Content automatically re-blurs after a delay you choose when the cursor leaves.

🎯

Selective contacts

Force-blur specific people/groups or mark trusted ones as never-blur.

🖥️

Screen-share mode

Extra protection when the window loses focus or during presentations.

🎨

Blur styles

Gaussian blur, pixelation-style or solid overlay — plus adjustable intensity.

🕶️

Incognito mode

Stronger privacy that also hides unread badges and notification indicators.

Install in under a minute

Developer mode — no Chrome Web Store required.

  1. 1
    Clone or download 
    git clone https://github.com/zuhaibbutt786/whatsapp-web-privacy-extension.git
  2. 2
    Open extensions page

    Go to chrome://extensions (or edge://extensions)

  3. 3
    Enable Developer mode

    Toggle the switch in the top-right corner.

  4. 4
    Load unpacked

    Click “Load unpacked” and select the project folder.

  5. 5
    Open WhatsApp Web

    Visit web.whatsapp.com — SafeWAChat is on by default.

Alt + X Quick toggle privacy on / off anytime

Built for privacy

No data collection

SafeWAChat never reads or stores the content of your messages.

No external servers

Zero network requests. Everything runs locally in your browser.

Local settings only

Preferences are saved with chrome.storage.sync — nothing leaves your devices.

Open source

Full source code is public on GitHub. Audit it, fork it, improve it.
