About the creator

Hi, I’m Zuhaib Hussain Butt. I build practical tools that respect your privacy and stay out of the way.

SafeWAChat started from a simple need: keeping WhatsApp Web private when working in public places, shared offices, or while presenting on a screen. The goal was never complexity — just one clear purpose: blur what should stay private until you decide to look.

I believe privacy tools should be transparent, lightweight, and respectful of your data. No accounts, no tracking, no cloud — everything runs locally in your browser.

How it works

  1. Install the extension from the Chrome Web Store (or load it unpacked from GitHub).
  2. Open WhatsApp Web — content is blurred by default.
  3. Hover to reveal, or use Alt+X to toggle privacy on/off.
  4. Customize blur targets, delay, and style in the popup or options page.
